# Sprout 2.0 — UI/UX Case Study

A beginner-focused investing experience designed to make the first steps of investing clearer and less intimidating.

## Project Overview

Sprout 2.0 is a UI/UX design concept for first-time investors in India. The project explores how a simple homepage and a guided onboarding journey can help users understand account setup, document preparation and identity verification.

## Project Goals

- Make the first steps easier to understand.
- Explain document requirements before onboarding.
- Make verification states clear and reassuring.
- Design for mobile usability and accessibility.
- Balance visual quality with performance constraints.

## Deliverables

- Mobile homepage
- Desktop homepage
- Five onboarding screens
- Mascot and visual design system
- Clickable prototype
- UI/UX case study

## Design Approach

The design uses a restrained green palette, readable typography and a consistent visual language. The onboarding flow is organized around helping users understand one task at a time.

## Design Decisions

The proposed experience prioritizes mobile users, document readiness and clear verification feedback. These decisions are design hypotheses that would need usability testing and validation against real product data.
